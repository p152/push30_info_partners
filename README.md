# Push30 — Партнёры

Информационный сайт для отображения партнёрской сети фитнес-клуба Push30. На сайте представлены спортивные залы и партнёры со скидками в виде карточного грида с модальными окнами для просмотра полной информации.

## Технологии

| Слой | Технология |
|------|------------|
| Фреймворк | TanStack Start |
| UI | React 19, TanStack Router v1 |
| Сборка | Vite 7 |
| Стили | Tailwind CSS 4 |
| Иконки | Lucide React |
| Язык | TypeScript 5.7 |
| Деплой | Netlify |

## Структура

- **Залы (основные)** — 251 партнёр с тарифами «Стандарт» и «Плюс»
- **Дискаунт** — 20 партнёров со скидками

## Запуск локально

```bash
npm install
npm run dev
```

Сервер запустится на [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
```
