# Push30 — Партнёры

Информационный сайт для отображения партнёрской сети фитнес-клуба Push30. Карточный каталог спортивных залов и партнёров со скидками с модальными окнами, поиском и фильтрацией.

## Технологии

| Слой | Технология |
|------|------------|
| Фреймворк | TanStack Start |
| UI | React 19, TanStack Router v1 |
| Сборка | Vite 7 |
| Стили | Tailwind CSS 4 |
| Иконки | Lucide React |
| Язык | TypeScript 5.7 (strict) |
| Деплой | Netlify |

## Каталог

- **Залы (основные)** — 251 партнёр с тарифами «Стандарт» и «Плюс»
- **Дискаунт** — 20 партнёров со скидками

Карточки фильтруются по категории услуги (тренажёр, йога, бассейн, спа, танцы, боевые искусства, развлечения), тарифу и поисковому запросу.

## Запуск локально

```bash
npm install
npm run dev
```

Сервер запустится на [http://localhost:3000](http://localhost:3000).

## Запуск через Docker

### Dev-режим

```bash
docker compose up
```

Сайт будет доступен на [http://localhost:3000](http://localhost:3000).  
Правки в исходниках применяются мгновенно благодаря монтированию тома.

### Preview (production-сборка)

```bash
docker compose --profile preview up app-preview
```

Сайт будет доступен на [http://localhost:4173](http://localhost:4173).

### Остановка

```bash
docker compose down
```

## Сборка

```bash
npm run build
```

Артефакты попадают в `dist/client/` — этот каталог публикуется на Netlify.

## Деплой

Проект деплоится автоматически через Netlify при пуше в основную ветку.  
Настройки сборки указаны в `netlify.toml`:

```toml
[build]
  command   = "vite build"
  publish   = "dist/client"
```
